# Poster-Maker

> 나이 드신 자영업자 사장님들을 위한 메뉴판·포스터 디자인 도구

AI 생성 이미지 특유의 "우글거림" 없이, 실제 사진 기반 보정 + 검증된 템플릿 선택 구조로 누구나 괜찮은 메뉴판을 만들 수 있게 한다.

---

## 문제 인식

요즘 자영업자들 사이에서 AI로 만든 메뉴판·입간판이 급속히 퍼지고 있다. 그런데 젊은 손님들은 그걸 보고 거부감을 느끼고 그냥 지나친다.

**왜 이 문제가 생기는가:**

1. **AI 이미지 특유의 우글거림** — Diffusion 모델이 텍스처를 재해석할 때 없는 것을 만들어내면서 발생
2. **딸깍 도파민** — "생성됐다 = 됐다"는 심리가 자기검열을 꺼버림. 결과물이 나오는 순간 완성됐다는 느낌이 들어 객관적 판단이 무너짐
3. **지적에 대한 방어** — "내가 만든 것"이라는 소유감 때문에 피드백을 공격으로 받아들임
4. **AI 반감의 전이** — 사진 자체의 미감 문제라기보다, "이거 AI 슬롭이네"라는 인식이 먼저 오고 그 불쾌감이 음식·가게 전체로 번짐

**기존 접근의 한계:**

- "잘 쓰면 된다" → 무책임한 말. 일선 자영업에서 맞닥뜨리는 모든 일을 혼자 처리하면서 미감까지 아는 건 대부분의 사람에게 불가능
- 프롬프트 가이드 제공 → 아무리 잘 만들어도 AI티가 보이는 순간 끝
- 피드백/검수 레이어 → 지적받으면 화냄. 자존심 건드리지 않으면서 개선하기 어려움
- 획일화된 템플릿 → AI티와 다른 의미의 "싸 보임"

---

## 해결 방향

**핵심: 생성을 최소화하고, 보정을 최대화한다**

AI를 음식 사진을 *만드는* 데 쓰지 않는다. 사장님이 직접 찍은 사진을 *괜찮게 다듬는* 데만 쓴다.

**왜 이게 맞는 방향인가:**
- 실제 사진 → AI티 없음, 음식이 실제처럼 보임, 손님 실망 없음
- 검증된 템플릿 안에서 선택 → 어떻게 골라도 최소한은 됨
- 사장님이 직접 고른 것 → "내 것" 느낌 유지, 자존심 안 건드림
- "20-30대 손님 반응 좋은 스타일이에요" 한 줄 → 지적이 아닌 정보 제공

Canva가 템플릿으로 디자인을 민주화했듯, 이 앱은 **자영업 메뉴판 미감을 민주화**한다.

---

## 앱 구조 (MVP)

```
1. 사장님이 폰으로 찍은 음식 사진 업로드
        ↓
2. AI 보정 (밝기 / 색감 / 배경 정리)
        ↓
3. 업종별 검증된 템플릿 선택
   - 냉면집용 / 국밥집용 / 카페용 / 분식집용 ...
   - 예시 미리보기로 고를 수 있게
        ↓
4. 텍스트 입력 (메뉴명 / 가격)
        ↓
5. 완성 & 다운로드
```

**MVP 핵심은 딱 두 가지:**
- 사진 보정 (배경 제거 + 색보정)
- 템플릿 끼워넣기

## 기술 스택 (제안)

### 이미지 처리 (비용 최소화 구조)

AI를 세 단계로 분리해서 API 호출을 최소화한다:

```
1단계: rembg (오픈소스, 무료)
       → 배경 제거

2단계: OpenCV (로컬 처리, 무료)
       → 밝기 / 색감 보정

3단계: GPT-4o Vision (API, 유료)
       → "이 사진 메뉴판에 써도 괜찮아요?" 검수만
```

3단계만 API 호출 → 비용이 거의 없음

### AI 이미지 생성이 필요한 경우 (선택적)

우글거림 없이 뽑는 프롬프트 방향:

```
❌ 피해야 할 키워드
hyperrealistic, photorealistic, 8k, ultra detailed,
highly detailed, intricate

✅ 쓰면 좋은 키워드
clean, minimal, flat lighting, simple background,
food photography style, soft natural light
```

**GPT API 비용 절감 팁:**
- 업로드 전 클라이언트에서 1024px 이하로 리사이징 → Vision 토큰 대폭 절감
- DALL-E는 `standard` quality만 사용 (`hd`는 2배 비쌈)
- 스타일은 `natural` (`vivid`보다 덜 복잡하게 나옴)

### 프론트엔드

```
React + 드래그 앤 드롭
SVG 기반 템플릿 (Canva 방식)
```

## 유통 전략

타겟이 명확하다: **50대 이상 자영업자**

- **소진공 (소상공인시장진흥공단)** — 정부 기관이라 신뢰도 높음, 연계 시 홍보비 없이 유입 가능
- **자영업자 쉼터, 장사의신** 등 네이버 카페 — 매출·운영 고민 많이 올라오는 커뮤니티
- **자영업 유튜버 협업** — 타겟 정확히 맞음

## 참고: 왜 AI 생성 메뉴판이 문제인가

SNS에서 퍼진 실제 사례들:

- 막국수 AI 생성 이미지가 메뉴판에 올라간 것을 보고 "속 메슥거린다"는 반응
- 검은 붓질 + 흰색 빨간 캘리 + AI 캐릭터 입간판 → "이 가게 2-3개월 내 폐업 확률 98%" 밈
- "징그럽다고 그렇게 얘기 나오는데 왜 AI 메뉴판 역병이 도는 거야" — 미감 문제라기보다 AI 반감 + 슬롭 느낌의 연장선

**핵심 인사이트:** 문제는 미감이 아니라 "AI티"다. 아무리 잘 만들어도 AI인 게 보이는 순간 끝난다. 그래서 AI 생성을 쓰지 않는 방향이 맞다.
